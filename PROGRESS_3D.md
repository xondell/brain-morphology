# 3D upgrade

- Пять глав расширены 3D: `intro`, `architecture`, `lobes`, `deep`, `stem`.
- Реальная GLB-модель BodyParts3D © DBCLS (компоновка Brain Anatomy Game / Pyae Sone Myo, CC BY-SA 2.1 JP), источник и Git SHA зафиксированы.
- Один рендерер Three.js, выделение именованных мешей, ghost-материал для остальных, клик на область, вращение и zoom, синхронизация с карточками.
- `brain3d.js` не меняет анатомическую геометрию, 2D fallback сохранён, WebGL/CDN при недоступности не блокируют слайды.
- Для локального копирования GLB: `bash scripts/download-anatomy-model.sh`; GitHub workflow добавляет модель в репозиторий.
- Нет отдельного меша мозолистого тела — для него 2D-сагиттальный срез.
- Тестировать на реальном подключённом браузере с WebGL, Three.js и GLB после публикации (среда разработки без внешней сети).
