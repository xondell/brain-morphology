# NEURO 3D — immersive redesign

- Сохранена независимая новая версия исходной 10-главной презентации, предыдущий проект не затронут.
- Для всех 10 глав используется **одна общая полноэкранная сцена** на Three.js с real GLB.
- Удалены рамки 3D-карточек. Текст слева выдвигается/скрывается одной кнопкой или клавишей H.
- Локальная геометрия не создаётся. Сегменты BodyParts3D окрашиваются и фокусируются по имени mesh; остальные становятся полупрозрачными с Fresnel-контурами.
- 3D на всех главах, выбор частей на 1–9, на десятой подсветка зависит от номера вопроса; вращение, zoom и reset доступны.
- На оболочках и развитии используются только условные акценты взрослой модели с явными предупреждениями.
- Переработана мобильная компоновка (390x844) и projector layout (1366x768).
- Проверен JS синтаксис с node --check, а также 2D UI через Playwright в Chromium (с отключённым удалённым 3D из-за сетевой политики среды).
- Прямой WebGL с GLB не проверен: исходный бинарный файл не удалось скачать из этой среды. GitHub Actions / скрипт установки получают GLB, проверяют Git SHA.
