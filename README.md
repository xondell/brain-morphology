# NEURO — Морфология головного мозга

**Интерактивная веб-презентация на русском языке** для школьного выступления (10 класс, ориентировочно 9–11 минут). Создана по требованиям навыка `interactive-presentation-creator`.

## Быстрый запуск

1. Распакуйте архив `brain-morphology-interactive.zip`.
2. Откройте `index.html` двойным щелчком в современном браузере (Chrome / Firefox / Edge): **подключение к интернету для презентации не требуется**.
3. Для демонстрации по локальной сети или во избежание ограничений `file://` можно из папки проекта выполнить:

   ```bash
   python3 -m http.server 8000
   ```

   Затем откройте `http://localhost:8000`.

Для публикации достаточно разместить статические `index.html`, `styles.css` и `app.js` на GitHub Pages, Vercel Static, Netlify или обычном веб-сервере. **Публикация за пользователя не выполнялась.**

## Управление

- `←`, `→`, `Space`, `PageUp`, `PageDown` — смена главы (если фокус не на элементе управления).
- `Home`, `End` — первая / последняя глава.
- `N` — заметки докладчика; **в этой версии они видимы на экране**, не использовать как приватный суфлёр.
- `F` или кнопка `⛶` — полноэкранный режим (если браузер разрешит).
- `Esc` — закрыть диалог.
- `☰ Изучение` — режим свободной вертикальной прокрутки всех глав, повторное нажатие возвращает показ.
- Интерактивные подписи, кружки на сагиттальном срезе, доли на латеральной схеме, шаги ликвора и варианты ответов работают по клику/клавиатуре.

При включённом режиме «Уменьшить движение» переходы сокращаются, а автопоказ ликвора отключается.

## Научная точность

- Авторские SVG — **учебные схемы, не в масштабе, не медицинские 3D-сканы**. Отдельные формы упрощены для школьной аудитории.
- Деление на четыре видимые латеральные доли и глубокую островковую долю не исключает другие морфофункциональные подходы к выделению лимбической доли.
- Упрощённая схема ликвородинамики представляет основной путь через желудочки в подпаутинное пространство, без всех тонкостей продукции, циркуляции и резорбции ликвора.
- Эмбриологическая схема показывает основные производные, а не полную временную последовательность формирования мозговых структур.

Источники доступны в кнопке «Источники» внутри приложения и в `docs/SOURCES.md`. Внешние ссылки не появляются внутри глав во время доклада.

## Структура

- `index.html`, `styles.css`, `app.js` — полный автономный проект, без сборщика/платных API/шрифтов/серверов.
- `docs/PROJECT_BRIEF.md` — бриф и допущения.
- `docs/STORYBOARD.md` — главы, действия и оценки времени.
- `docs/SOURCES.md` — научные источники.
- `docs/ASSET_CREDITS.md` — происхождение визуалов.
- `PROGRESS.md` — готовность и проверенные ограничения.

## Использование в классе

Рекомендуется 16:9 и полноэкранный режим. При работе на старом проекторе уменьшите масштаб браузера только если не помещается текст: в проекте предусмотрена светлая, контрастная тема. Сначала пройдите интерактивные слайды 02–09, затем откройте тест и предложите отвечать аудитории перед каждым кликом.
