# Морфология головного мозга — NEURO 3D / Cinematic

Полноэкранная интерактивная 3D-презентация для проектора и телефона (10 глав, русский язык). Модель мозга занимает **всю область экрана**, текст слева складывается кнопкой, структуры выделяются цветом, остальные сегменты становятся прозрачными с подсветкой контура.

**Модель не придумана и не нарисована:** сегментированный BodyParts3D GLB из [Brain Anatomy Game](https://github.com/Rickaym/brain-game) (copyright DBCLS, CC BY-SA 2.1 Japan). Автор компоновки исходного набора — Pyae Sone Myo. Обязательная атрибуция: `docs/ASSET_CREDITS.md` и окно «Источники» в презентации. В текущей ветке модель уже включена в репозиторий как `assets/brain.glb`. Установочный скрипт позволяет повторно скачать и проверить её; при недоступности локального ресурса приложение также пробует оригинальный GitHub-источник.

## Возможности

- Полноэкранный 3D-рендер (без отдельной рамки/карточки).
- 10 глав с отдельными выбранными структурами и автоматической сменой ракурса.
- Кнопки слева: выбрать лобную, теменную, височную, затылочную долю, таламус, гипоталамус, мозжечок, отделы ствола и др.
- Выбранные меши подсвечиваются, остальные показываются прозрачными с Fresnel-силуэтом.
- Мышь/тачпад: тянуть для вращения; колёсико для масштаба; справа внизу управление.
- Кнопка «Скрыть текст» оставляет мозг на весь экран; клавиша `H` делает то же.
- Стрелки ← → переходят между слайдами; `N` — заметки, `F` — полноэкранный режим.
- Вопросы 1–7 связаны с подсветкой соответствующих структур модели.
- При недоступности WebGL/модели используется учебная 2D-схема, текст продолжает работать.

## Установка локально

```bash
bash scripts/download-anatomy-model.sh
bash scripts/install-three-vendor.sh
python3 -m http.server 8000
```

Затем открыть `http://localhost:8000`. Для установки требуются Git, curl, Node.js/npm; скачанные GLB и JS находятся в `assets/` и `vendor/`. Прямой запуск через `file://` не поддерживается браузерными ES-модулями.

## GitHub Pages

Публичный репозиторий `xondell/brain-morphology` публикует корень ветки `main`. После загрузки файлов workflow `.github/workflows/install-open-anatomy.yml` скачивает **проверенный** GLB и Three.js, сохраняет их в самом репозитории и обновляет Pages. Используйте `deploy-brain-immersive.sh`, приложенный отдельно, если хотите отправить этот проект со своего Linux.

Адрес после публикации: https://xondell.github.io/brain-morphology/

## Научная корректность визуализации

- Оболочки мозга **не представлены отдельными мешами** в исходном атласе. Цветовые режимы на соответствующей главе **условны** и обозначают анатомический порядок, а не толщину/геометрию оболочек.
- Модель — **мозг взрослого человека**. Подсветка на эмбриологическом слайде указывает производные мозговых пузырей, а не реальные эмбриональные формы.
- Водопровод мозга и субарахноидальное пространство отмечены косвенно, они не моделируются как точные полости.
- Мозолистое тело в выбранном GLB отсутствует в виде отдельного меша — оно объясняется текстом, не выделяется ложной 3D-формой.
- Модель образовательная и не предназначена для диагностики.
