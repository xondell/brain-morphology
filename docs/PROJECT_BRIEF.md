# Бриф

- **Название:** Морфология головного мозга.
- **Режим навыка:** BUILD.
- **Аудитория:** школьная, уровень 10 класса (допущение).
- **Язык:** русский.
- **Продолжительность:** около 9–11 минут (допущение).
- **Сценарий:** выступление с проектором + самостоятельное изучение на телефоне.
- **Формат:** самостоятельный статический сайт, открывается offline через `index.html`.
- **Цель:** различать крупные отделы мозга, доли, важные борозды и внутренние структуры, оболочки, желудочки и эмбриологические источники основных отделов.
- **Визуал:** светлая медицинская научно-популярная типографика; пастельные цвета используются систематически для областей.
- **Интерактивы:** 2 авторских вида мозга, кликабельные доли/структуры, слои, ликвородинамика, финальный тест.
- **Ограничения:** никаких аккаунтов, скачивания закрытых моделей, внешних JS-пакетов, платных API и сетевых запросов. Внутренние рисунки — схемы, не сканы.
- **Отдельное решение:** медицинская достоверность важнее декоративного недостоверного 3D; сложная 3D-модель не добавлена.
