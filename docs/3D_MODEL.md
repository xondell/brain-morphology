## Интеграция

Код `brain3d.js` загружает один GLB для пяти слайдов и использует **один** WebGL-контекст: `<canvas>` перемещается между экранами, чтобы не создавать пять тяжёлых сцен и не перегружать телефоны.

При выборе отдела:
1. меши, относящиеся к анатомической группе, окрашиваются и подсвечиваются;
2. остальная геометрия становится полупрозрачной для сохранения контура;
3. можно повернуть мозг курсором/пальцем, увеличить колесом и восстановить ракурс кнопкой;
4. выбор в тексте и клик по видимому мешу синхронизированы.

Островок находится глубоко; остальная ткань при выборе становится почти прозрачной. **Мозолистое тело** не представлено самостоятельным мешем в выбранной модели: при его выборе показывается исходный сагиттальный 2D-срез. Это лучше, чем подсвечивать неправильную область.

## Установка модели для полностью автономного GitHub Pages

```bash
bash scripts/download-anatomy-model.sh
```

После загрузки `assets/brain.glb` включите его в Git-коммит. В репозитории также имеется workflow `.github/workflows/install-open-anatomy.yml`, который может загрузить и добавить в репозиторий модель с проверкой контрольной суммы. Если локального файла нет, браузер попробует загрузить GLB напрямую из фиксированного публичного репозитория-источника.

**Примечание об интернете:** движок Three.js / GLTFLoader загружается с CDN, поэтому для 3D требуется интернет. Без доступа к 3D-ресурсам презентация продолжает работать как интерактивный 2D-атлас. При желании зависимости Three.js можно разместить локально отдельно.

## Образовательные пределы

Эти 3D-сетки предназначены для изучения макроскопического строения. В выбранном исходнике отдельные крупные доли состоят из нескольких гирусов, а не сплошной поверхности одной доли. **Не использовать** для диагностики, планирования вмешательств или точных измерений. Некоторые анатомические ориентиры представлены схематически в 2D (например, на слайде об оболочках).
